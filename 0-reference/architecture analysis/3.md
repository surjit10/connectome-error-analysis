## 3. Architecture Changes

### 3.1 NetworkX → igraph (complete)
- `modules/preprocessing/pipeline.py` now explicitly checks `isinstance(graph, igraph.Graph)` and raises `TypeError` if anything else is passed.
- Zero `import networkx` or `import nx` anywhere in the execution pipeline.
- The dead placeholder `graph.es.select(_source_eq=None)` that would have raised `TypeError` at runtime was removed from `validator.py`.

### 3.2 Configuration System (Phase 002)
- `ConfigManager` loads `configs/defaults.yaml` on construction.
- All schemas in `configs/schemas/` are loaded and used for validation.
- `FrozenConfig` prevents mutation after loading via `__setattr__` override.
- Merge order is strictly enforced: defaults → dataset → error_model → analysis → experiment.

### 3.3 Dataset Registry (Phase 003)
- `DatasetRegistry` scans `configs/datasets/` once on construction.
- `DatasetInfo` carries: `name`, `version`, `dataset_dir`, `is_fafb`, `files` dict, `required_*_columns`.
- `DataLoader` now calls `registry.lookup(dataset_name)` and `load_dataset_from_info(info)` — no hardcoded paths remain in `data_loader.py`.
- Legacy fallback (`_legacy_resolve`) preserved for backwards compat when no YAML exists for a dataset.

### 3.4 Baseline Feature Extraction (Phase 006)
- `PreparedGraph` now has a `baseline_features: dict` field.
- `preprocess_graph()` calls `_extract_features()` as Step 4.
- Features computed: `indegree`, `outdegree`, `total_degree`, `pagerank`, `reciprocal_ratio`, `hub_neighbor_count`, `two_hop_size`.
- All features controlled by `feature_config` dict — can be individually disabled.
- Features are computed **once** and reused; the `ExperimentRunner._build_temp_graph()` skips recomputation on perturbed graphs and copies baseline features to the temp `PreparedGraph`.

### 3.5 Experiment Runner (Phase 009)
- `ExperimentConfig` gains: `configs_root`, `baseline_analysis_names`, `output_root`, `create_zip`.
- Pipeline now has 8 steps: Load → Build → Preprocess → Baseline Analyses → Error Model → Temp Graph → Analyses → Export.
- `_step_export()` triggers `StatisticsEngine.aggregate()` → `MetadataManager.collect()` → `ExportManager.export()` automatically when `output_root` is set.
- Temporary graph deleted immediately after analysis via `del temp_graph`.

### 3.6 core/__init__.py cleanup
- 36 public symbols now exported (was 19).
- Grouped by layer: Data, Registry, Configuration, Graph, Experiment, Statistics/Export, Runtime.
