## 5. Architecture Diagram

```
CSV files (gzip)
    │  polars.read_csv (no pandas)
    ▼
FlyWireDataset (neurons: pl.DataFrame, connections: pl.DataFrame)
    │  GraphBuilder.build()
    │  polars.to_list() → igraph.add_vertices / add_edges
    ▼
igraph.Graph  (C arrays, id_to_idx/id_map stored as graph attrs)
    │  preprocess_graph()
    │  GraphValidator → ValidationReport  (igraph API)
    │  build_metadata → GraphMetadata     (igraph API)
    │  build_lookup   → GraphLookup       (igraph API)
    ▼
PreparedGraph  (IMMUTABLE BASELINE — wraps igraph.Graph by reference)
    │
    ├── [Baseline run] → analyses run directly on PreparedGraph
    │
    └── [Perturbed run]
            │  BaseErrorModel.execute(prepared, config, seed)
            │    rng = numpy.random.default_rng(seed)   ← local RNG
            │    _perturb(prepared, config, result, rng)
            │    → result.edge_mask   [bool × E]
            │    → result.weight_updates {int: float}
            │    (baseline graph NEVER touched)
            ▼
         ErrorResult (edge_mask + weight_updates, no graph object)
            │
            │  ExperimentRunner._build_temp_graph()
            │    igraph.Graph.subgraph_edges(active_indices)
            │    apply weight_updates
            ▼
         TEMPORARY igraph.Graph  (exists only during analysis)
            │  preprocess_graph() → PreparedGraph (temp)
            │  analysis.execute(temp_prepared)
            ▼
         AnalysisResult (metrics dict)
            │
            │  del temp_graph  ← DESTROYED IMMEDIATELY
            ▼
         ExperimentResult → StatisticsEngine → ExportManager
```

## 6. Data Flow

```
load_dataset()
    polars.read_csv → pl.DataFrame (neurons, connections)

GraphBuilder.build(dataset)
    pl.DataFrame.to_list() → Python lists
    → igraph.add_vertices(n)
    → igraph.vs["root_id"] = root_ids
    → igraph.vs[col] = col_values
    → igraph.add_edges(edge_list)
    → igraph.es[col] = edge_values
    → graph["id_to_idx"] = {root_id: vertex_index}
    → graph["id_map"]   = {vertex_index: root_id}

preprocess_graph(igraph.Graph)
    GraphValidator.validate(graph)  → ValidationReport
    build_metadata(graph)           → GraphMetadata
    build_lookup(graph)             → GraphLookup
    PreparedGraph(graph, …)         → immutable baseline

BaseErrorModel._perturb(prepared, config, result, rng)
    rng.random(E) >= rate           → bool array
    result.edge_mask = mask.tolist()

ExperimentRunner._build_temp_graph()
    active = [i for i,m in enumerate(mask) if m]
    temp = baseline.subgraph_edges(active, delete_vertices=False)
    → preprocess_graph(temp)
    → analysis.execute(temp_prepared)
    → del temp

ExportManager.export(result, metadata, stats)
    metadata.json, config_snapshot.yaml, summary.csv,
    trial_results.csv, runtime_report.txt, README.md, .zip
```

## 7. Memory Improvements

| Before | After | Saving |
|---|---|---|
| pandas DataFrame (dict-of-arrays + index overhead) | Polars DataFrame (Apache Arrow columnar) | ~30-50% RAM for same data |
| NetworkX `nx.DiGraph` (Python dict-of-dicts, ~200–500 bytes/edge) | igraph.Graph (C arrays, ~20–50 bytes/edge) | ~5–10× lower graph RAM |
| Full graph deep copy per experiment (`graph.copy()`) | No copy — edge_mask is a bool list (1 bit/edge) | Near-zero perturbation overhead |
| Perturbed PreparedGraph kept in RAM alongside baseline | Temporary subgraph deleted after analysis | Reduces peak RAM by ~graph_size |
| pandas DataFrames survive entire pipeline | `del dataset` after graph is built | Frees DataFrame RAM early |

## 8. Performance Improvements

| Bottleneck | Before | After |
|---|---|---|
| Data loading | Pandas read_csv (Python objects per cell) | Polars read_csv (vectorised Arrow; ~2–5× faster) |
| Graph construction | `itertuples` row-by-row, dict allocation per node/edge | Bulk `pl.to_list()` + igraph C-level bulk add |
| Graph copy per experiment | O(V+E) deep copy | O(E) mask creation (bool list) |
| Temp graph construction | N/A (was full copy) | `subgraph_edges()` — O(active_E), C-level |
| RNG | `random.seed()` / `np.random.seed()` global state | `numpy.random.default_rng()` local, no global state |

## 10. Risks

| Risk | Severity | Mitigation |
|---|---|---|
| igraph `subgraph_edges(delete_vertices=False)` copies all vertex attributes | Medium | Vertices are cheap vs edges; acceptable for Kaggle scale |
| Polars `infer_schema_length=10_000` may mistype IDs on large files | Medium | Monitor root_id dtype after load; consider `schema_overrides` if needed |
| `graph.is_loop()` accepts edge index — confirmed igraph API | Low | Tested against igraph docs |
| `edge_mask` as Python `List[bool]` for very large graphs (50M+ edges) | Low | numpy bool array would save ~8× more RAM; TODO if needed |
| `psutil` not installed on Kaggle by default | Low | `RuntimeMonitor` gracefully falls back to `resource` module |
| `preprocessing/__init__.py` unchanged — still exports `PreparedGraph` correctly | None | Verified — no changes needed |
