# Common Checklist

Every implementation prompt must verify the following items upon completion:

- [ ] Repository inspected and current state confirmed.
- [ ] Dependencies satisfied (upstream phases merged).
- [ ] Previous phase completed successfully.
- [ ] Interfaces verified against real source code.
- [ ] Tests still pass (`pytest tests/`).
- [ ] No duplicate logic introduced.
- [ ] Architectural constraints respected.
- [ ] Documentation updated to reflect changes.
