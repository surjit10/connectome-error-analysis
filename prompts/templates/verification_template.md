# Verification Template

## Pre-Implementation Verification Checklist

1. **Verify Interfaces**:
   - Inspect `[Target Interface]`. Does it match the expected signature?
2. **Verify Dependencies**:
   - Inspect `[Dependency File]`. Is the upstream phase completed?
3. **Verify Configuration**:
   - Inspect `[Config File]`. Are the required parameters present?
4. **Verify Tests**:
   - Run existing tests to ensure baseline stability before starting.

**Rule:** Stop execution and report mismatches if any check fails.
